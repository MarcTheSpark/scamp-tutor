# SCAMP AI Tutor

Instructions and reference material that turn an AI assistant into a tutor for
[SCAMP](https://scamp.marcevanstein.com).

**With a chatbot:** follow the instructions at <https://marcthespark.github.io/scamp-tutor/>.

**With a coding agent** (Claude Code, Codex, Cursor, Gemini CLI, ...): clone this repo, start
the agent in it, and say hi. `AGENTS.md` sets it up as your tutor (`CLAUDE.md` and
`GEMINI.md` just point to it). Put your own scripts in `my_work/`.

## Layout

- `tutor/`: everything the tutor reads, also served as the website. `tutor.txt` (teaching
  instructions), `resources.txt` (map of the docs and examples), `stumblingBlocks.txt`
  (SCAMP facts AIs get wrong), and the `docs/` and `examples/` bundles. The `.html` files are
  linked copies of the text files, for chatbots that won't follow plain-text URLs.
- `my_work/`: yours.

The bundles and `.html` copies are generated by scripts in
[scamp-meta](https://github.com/MarcTheSpark/scamp-meta) (`docs/scripts/tutor/`), where this
repo is a submodule. After hand-editing a text file in `tutor/`, rerun `build_html.py` there.
